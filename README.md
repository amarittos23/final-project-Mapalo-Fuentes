## Problem
CodeCode solves the problem of students who had hard time to find simple, organized, and interactive resources for learning HTML, CSS, and JavaScript. It is designed for BSIT 1st-year students of Northern Bukidnon State College (NBSC), particularly beginners with little or no programming experience who need an accessible platform to understand coding concepts and practice their skills.

## Solution
CodeCode solves this problem by providing an interactive web-based learning platform with organized HTML, CSS, and JavaScript lessons, coding examples, an interactive code playground, quizzes with automatic scoring, coding trivia, and simple coding challenges. It also includes progress tracking and student profiles to help learners monitor their completed lessons, quiz scores, and achievements while learning at their own pace.

## Main Feature

## Pages
1. Homepage – Displays the introduction to CodeCode, featured learning content, and navigation to different sections.
2. App Page – Provides the main learning area where students access HTML, CSS, and JavaScript modules.
3. Code Playground Page – Allows students to write, edit, and experiment with code.
4. Quiz and Challenges Page – Displays interactive quizzes and coding challenges to test students' knowledge.
5. Student Profile Page – Shows completed lessons, quiz scores, earned badges, and learning progress.
