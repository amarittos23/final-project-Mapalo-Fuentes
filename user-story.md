# CODECODE User Stories

## US1 — Learn a language step by step
As a beginner BSIT student, I want complete HTML, CSS, and JavaScript learning paths with simple explanations, examples, and small tasks so that I can learn concepts in a clear order.

## US2 — Understand each example
As a student, I want code samples, plain-language notes, analogies, and expected results so that I can understand what the code does before experimenting.

## US3 — Practice in a guided playground
As a student, I want to choose HTML, CSS, or JavaScript examples, edit the code, run it, and see a preview so that I can learn through experimentation without setting up another tool.

## US4 — Check my knowledge
As a student, I want separate quizzes for HTML, CSS, and JavaScript with feedback and explanations so that I can identify which topics I understand and which need more practice.

## US5 — Keep quiz results current
As a student, I want my latest quiz attempt for each subject to update my saved result when I retake it so that my profile reflects my current performance.

## US6 — Track my learning progress
As a student, I want to see completed lessons, quiz results, an overall progress indicator, and achievements so that I can recognize my progress and stay motivated.

## US7 — Personalize and keep a copy of progress
As a student, I want to set a display name and download my progress report so that I can identify my learner profile and keep a copy of my results.

## US8 — Use the platform on different screens
As a student, I want the pages and controls to adapt to desktop and mobile screens and be usable with a keyboard so that I can learn comfortably on different devices.
